# RP 数据库、主动上下文与最后一步接入

日期：2026-10-25。用户已批准实现。新建独立 `dsh-rp-database` 与 `dsh-rp-context`，更新 `dsh-rp-last-step`；沿用 DSH 0.2.1-rc.2 原生宿主、Node 24、独立打包和可选服务。

## 用户确定的边界

- 数据库取代依附 Agent preset 的世界书。来源版本固定，故事继承后只改自己的会话覆盖；原文件和其他故事不变。
- 人类设置 `readOnly` 与 `mode: auto|required|disabled`。只读管内容修改，mode 管选材；禁用不能经直接读取或搜索绕过，必开不能被中间模型踢掉。
- 不做公开／GM／NPC 权限体系。人物知情、传闻、推测和揭示条件使用自由文本 `notes`，由中间 GM 判断。
- 检索由关键词、可配置 embedding、rerank 提供候选；GM 能读候选、搜索候选外条目、排序选材、新建修改及临时备注。程序执行权限、版本和预算，GM 决定语义。
- 历史原文保留。默认近 N 轮正式叙事完整、更早用摘要；GM 能按来源引用展开、压缩或降到索引。否定、回退与失败稿不能当作当前剧情召回。
- 最后一步接收冻结选材，继续管理文风模块；writer 没有数据库修改权限。规范正文接受后才纳入正式叙事历史，重写正文复用已确定材料。

## 独立组件

`rpDatabase` 拥有来源数据库及不可变版本、会话覆盖、条目权限、关键词/向量/重排、变更引用与原生编辑器。它不解释正文或 NPC 权限，也不执行导入脚本。

`rpContext` 拥有正式叙事记录、回合摘要、可逆上下文表示、GM 选材循环和冻结材料。它消费可选 `rpDatabase`，可单独仅管理历史。每个 GM 调用是有界的独立模型阶段，不是常驻多 Agent 团队。

`rpLastStep` 在提示词热组装之前调用可选 `rpContext.prepare`，将冻结的数据库选材、历史片段、叙事备注和最近正文交给 writer；未安装新插件时保留 0.1 行为。Loop Studio 可选注册 GM、摘要和检索阶段，宿主原选择不被全局改写。

## 引用、分支与提交

来源采用数据库 ID、版本、条目 ID/版本。运行中修改另记录会话、规范 assistant/message 标识与工具调用或来源事件；不单凭文本 hash 或可能复用的 provider call ID 判断归属。

数据库变更和历史表示只在其所属来源仍位于当前有效分支时参与读取。分叉继承分叉点状态；被回退的后续变更、临时备注和历史不会通过检索复活。原件与历史记录可供人类回溯。原生读使用 owner Remote 授权，Agent 只处理调用会话。

GM 先在隔离工作副本上读取/搜索/调整，通过权限与 revision 检查后提交数据库变化并冻结材料；writer 失败不会授权重跑既有事实工具。正式正文和数据库事务分别有提交记录。所有观察者不在 Session 发布回调中追加事件。

## 最小数据

条目：`id,title,content,keywords,tags,notes,readOnly,mode,version`。notes 是普通文字，没有必填 NPC 列表。临时备注附本轮来源，默认仅本轮有效。导入支持本插件 JSON 与 ST 世界书 JSON，保留上传原文和未知字段但不执行。

材料：本轮方向包、选中条目内容快照/版本引用、选择顺序、历史表示及源引用、GM 的叙事指导、未决事项和临时备注。必开材料超过预算时明确报告，不静默删除。生成后不再临时读取可变化数据库。

历史：每条正式正文有规范来源、玩家输入、正文、事实摘要与未决事项。表示为 full/summary/index；省略只是当前请求的选择，原文不删除。默认窗口按已确认叙事回合计数，不按工具消息条数。摘要不能覆盖权威事实，用户提案不能因摘要而变成已发生事实。

## 外源参考

NVWA 双星纪提供了近楼正文/旧楼摘要、事实字段、未决事项和作者提案分离的实战案例。原 JSON 只作本地参考，不执行其 regex/TH 脚本，不将整份社区内容复制为测试或公开资源。

统一版 billion-context 的可逆压缩、展开、搜索和原文保留值得复用；其 DSH 实现需要先核验版本与组合效果，不能仅凭 README 宣称兼容。初版在自身 RP 材料投影上实现可逆表示，并通过可选适配边界接入现有压缩服务，避免替换宿主压缩后端或运行未经核验的上游程序。

本机 tavern2agent-dv-fork 已交 Astra 只读审查。其入口自称 DSH，但正文仍含 Pi 假设、缺失引用及没有附带实现的主张。仅借鉴提交后投影、来源引用和失败恢复；每卡造 runtime preset、NPC 权限系统和禁止资料 patch 的旧策略不采用。

## 验收

纯内核测试权限、来源不变、版本冲突、回退/分叉、禁用检索拒绝、向量与重排调用、降级声明及有界选材。原生隔离宿主用可识别的模拟 GM、embedding、rerank 与 writer，证明候选外搜索、历史展开/折叠、已选快照、每阶段实际模型、失败稿排除、重启和分支恢复。原生 UI 提供数据库继承/条目编辑、策略、覆盖变化和历史材料检查，侧栏/全屏/窄窗口通过。
